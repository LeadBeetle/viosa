# Privacy Policy for VIOSA

**Last updated:** [DATE]

## Introduction

VIOSA ("we", "our", or "the app") is an audio transcription application. This privacy policy explains how we collect, use, and protect your information.

## Data Collection

### Data We Collect

1. **Audio Recordings**
   - Voice recordings created within the app
   - Audio files you select for transcription
   - These are stored locally on your device

2. **Transcription History**
   - Text transcriptions of your audio files
   - Stored locally on your device using encrypted storage

3. **API Key**
   - Your OpenRouter API key (required for transcription)
   - Stored securely using encrypted device storage
   - Never transmitted to our servers

### Data We Do NOT Collect

- Personal identification information
- Location data
- Contact information
- Usage analytics
- Crash reports

## How We Use Your Data

Your data is used solely for:
- Converting audio to text via the OpenRouter API
- Storing your transcription history locally
- Providing app functionality

## Third-Party Services

### OpenRouter API

We use OpenRouter API for audio transcription. When you transcribe audio:
- Audio data is sent to OpenRouter's servers for processing
- Transcription results are returned to your device
- Please review [OpenRouter's Privacy Policy](https://openrouter.ai/privacy) for their data handling practices

## Data Storage

- All user data is stored **locally on your device**
- API keys are stored using secure encrypted storage
- Transcription history is stored in a local database
- No data is stored on our servers

## Permissions

The app requires the following permissions:

| Permission | Purpose |
|------------|---------|
| **Microphone** | Recording audio for transcription |
| **Storage Access** | Reading audio files for transcription, saving recordings |
| **Internet** | Communicating with OpenRouter API for transcription |
| **Foreground Service** | Continuing recording when app is in background |
| **Notifications** | Showing recording status |

## Data Security

We implement security measures including:
- Encrypted storage for sensitive data (API keys)
- Local-only data storage
- No cloud synchronization

## Your Rights

You can:
- Delete your transcription history within the app
- Remove your API key at any time
- Uninstall the app to remove all local data

## Children's Privacy

This app is not intended for children under 13. We do not knowingly collect data from children.
